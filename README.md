# My Portfolio Website

Hey! This is my personal portfolio website that I built as part of my BCA final year. I wanted a place to put all my projects and skills together in one spot instead of just explaining everything verbally whenever someone asks.

## About

I'm Purnima, a 4th year BCA student at Sagarmatha College of Science and Technology, Kathmandu. I've been learning web development for the past few years and this portfolio is kind of a summary of where I'm at right now. It's not perfect but I'm proud of it.

The site has four main parts — a hero/intro section, an about me section where I talk about my projects, a skills section, and a contact form at the bottom.

## Projects Featured

**SewaSathi** — This one is close to my heart. It's a service marketplace where people in Nepal can find local service providers (plumbers, electricians, tutors, etc.) and book them. The idea came from how hard it is to find reliable local help. Built it with PHP and MySQL for the backend.

**PawBliss** — A dog adoption platform that connects rescued dogs with potential adopters. I started this because I care about animal welfare and wanted to do something that actually helps. Also PHP/MySQL + JavaScript.

## Tech Stack

- HTML5 and CSS3 (flexbox, grid, animations)
- Vanilla JavaScript
- PHP
- MySQL

No frameworks used for the frontend — I wanted to understand the fundamentals properly before jumping into React or Vue. Maybe next year.

## How to Run

Just clone or download the repo and open `index.html` in your browser. No build tools, no npm install, nothing fancy.

```
git clone <your-repo-url>
cd portfolio
open index.html
```

If you want the profile image to show up in the nav, make sure `pt.png` is in the same folder as `index.html`.

## File Structure

portfolio/
